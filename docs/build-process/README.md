# Build process

FinPilot was built with an AI coding assistant (Claude Code), phase by phase. These files show how:

| File | What it is |
|---|---|
| [BUILD_PROMPT.md](BUILD_PROMPT.md) | The original brief: product scope, hard rules, data model and phases. |
| [AMENDMENT_1.md](AMENDMENT_1.md) | Changes to the brief (multi-currency, FX MCP server, dev tooling). It wins where the two conflict. |
| [PLAN.md](PLAN.md) | The merged plan and phase log, with every item checked off as it was finished. |
| [CLAUDE.md](../../CLAUDE.md) | The conventions and commands the assistant follows in every session (kept in the repository root, where the assistant reads it). |

The product documentation is in the repository root: [README.md](../../README.md), [DESIGN_NOTES.md](../../DESIGN_NOTES.md) and [DEPLOY.md](../../DEPLOY.md).
